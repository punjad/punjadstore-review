ไฟล์ในชุดนี้
- index.html: หน้าเว็บไซต์ responsive สำหรับลูกค้าและหน้าเข้าสู่ระบบแอดมิน
- config.example.js: ตัวอย่างการตั้งค่าการเชื่อมต่อ Supabase
- schema.sql: ตารางฐานข้อมูล, สิทธิ์การเข้าถึง, ระบบเครดิต และ Storage

ข้อสำคัญ
ชุดนี้เป็น source code ที่พร้อมนำไปติดตั้ง แต่ยังไม่ใช่ URL เว็บไซต์ออนไลน์ เพราะต้องเชื่อม Supabase และนำไฟล์ขึ้นโฮสต์ก่อน

ขั้นตอนติดตั้ง
1) สร้างโปรเจกต์ที่ https://supabase.com (เลือกแผนที่เหมาะสม)
2) ไปที่ SQL Editor แล้ววางเนื้อหาทั้งหมดใน schema.sql และกด Run
3) ไปที่ Authentication > Users แล้วสร้างบัญชีอีเมล/รหัสผ่านสำหรับเจ้าของร้าน
4) คัดลอก UUID ของบัญชีแอดมิน แล้วนำไปแทน THE-ADMIN-USER-UUID ในคำสั่งท้าย schema.sql จากนั้น Run
5) คัดลอก config.example.js เป็น config.js แล้วใส่ Project URL และ anon/public key จาก Project Settings > API
6) นำ index.html และ config.js ขึ้นโฮสต์แบบ static เช่น Netlify, Vercel หรือ Cloudflare Pages
7) เปิด URL เว็บไซต์บนมือถือเพื่อทดสอบส่งรีวิว อนุมัติรีวิว และตรวจเครดิต

กติกาเครดิต
- รีวิวที่อนุมัติ 1 รายการ = 1 เครดิต
- รีวิวที่ถูกปฏิเสธหรือยังรออนุมัติไม่ได้เครดิต
- ระบบป้องกันการให้เครดิตซ้ำจากการกดอนุมัติรายการเดิม

หมายเหตุความเป็นส่วนตัว
- LINE ID/รหัสลูกค้าไม่แสดงในรีวิวสาธารณะ
- การตรวจเครดิตใช้รหัสลูกค้าที่กรอกไว้ตอนส่งรีวิว จึงควรให้ลูกค้าใช้รหัสเดิมทุกครั้ง
- หากต้องการความปลอดภัยสูงขึ้น ควรเพิ่มระบบยืนยันตัวตนลูกค้าก่อนเปิดให้ใช้เครดิตแลกสิทธิ์จริง
- ควรเพิ่ม CAPTCHA / rate limit ก่อนเปิดให้สาธารณะใช้จริง เพื่อช่วยลดสแปม
